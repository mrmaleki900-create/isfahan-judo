# ISFAHAN JUDO OLYMPIC — Windows app

این پروژه فایل HTML برنامه را داخل یک پنجره دسکتاپ Electron اجرا می‌کند و با GitHub Actions نصب‌کننده ویندوزی `.exe` می‌سازد.

## ساده‌ترین روش ساخت EXE با GitHub

1. وارد GitHub شوید و یک مخزن جدید (New repository) بسازید؛ مثلاً `isfahan-judo-olympic`.
2. فایل ZIP این پروژه را در کامپیوتر Extract کنید.
3. همه محتویات پوشه را (از جمله پوشه مخفی `.github`) در مخزن GitHub آپلود کنید. راه مطمئن: در صفحه مخزن از **Add file → Upload files** استفاده کنید. پوشه `.github/workflows/build-windows.yml` باید دقیقاً در همین مسیر در مخزن قرار بگیرد.
4. تغییرات را با **Commit changes** ثبت کنید.
5. در مخزن به زبانه **Actions** بروید و workflow به نام **Build Windows installer** را باز کنید. اگر خودکار شروع نشده، **Run workflow** را بزنید.
6. صبر کنید تا همه مراحل سبز شوند. در اجرای موفق، بخش **Artifacts** پایین صفحه اجرا، فایل `ISFAHAN-JUDO-OLYMPIC-Windows-Installer` را نشان می‌دهد.
7. Artifact را دانلود و روی کامپیوتر Extract کنید؛ فایل `.exe` نصب‌کننده داخل آن است. آن را اجرا کنید و مراحل نصب را ادامه دهید.

## ساخت مستقیم روی ویندوز (اختیاری)

نیاز به نصب Node.js نسخه LTS از وب‌سایت رسمی Node.js دارید. سپس در این پوشه ترمینال باز کنید و اجرا کنید:

```bash
npm install
npm run dist
```

فایل نصب در پوشه `dist` ساخته می‌شود.

## نکات مهم

- این یک برنامه دسکتاپ بسته‌بندی‌شده با Electron است؛ برای نصب و اجرای برنامه به مرورگر جداگانه نیاز نیست.
- تصویر پس‌زمینه صفحه شروع از اینترنت بارگیری می‌شود، بنابراین برای نمایش آن اتصال اینترنت لازم است.
- موسیقی به صورت خودکار همراه برنامه نیست؛ در خود برنامه یک فایل صوتی انتخاب کنید. فقط از فایل‌هایی استفاده کنید که حق استفاده از آن‌ها را دارید.
- اطلاعات جدول در فضای ذخیره‌سازی همان برنامه/حساب ویندوز ذخیره می‌شوند. برای جلوگیری از از دست رفتن اطلاعات، از داده‌های مهم نسخه پشتیبان تهیه کنید.
- این بسته برای ویندوز 64 بیتی (x64) ساخته می‌شود. برای دستگاه‌های Windows ARM یا نسخه‌های 32 بیتی باید تنظیمات ساخت جداگانه انجام شود.
- این سورس شامل مجوز رسمی، تأییدیه فدراسیون یا قوانین رسمی قرعه‌کشی نیست؛ پیش از استفاده در مسابقات رسمی، نتایج و منطق قرعه‌کشی را کامل آزمایش کنید.


## امکانات نسخه به‌روزشده
- رابط کاربری فارسی با نام «جودو المپیک اصفهان»
- انتخاب رده سنی نونهالان، نوجوانان، جوانان و بزرگسالان
- انتخاب دلخواه نوع دسته وزنی (سبک‌وزن، سنگین‌وزن یا دلخواه) و واردکردن وزن دقیق توسط کاربر
- قطعه صوتی ورزشی کوتاه و ساخته‌شده برای صفحه شروع؛ پخش خودکار ممکن است بسته به سیاست صدای ویندوز/موتور برنامه مسدود شود
- ورود صوتی فارسی با دکمه «ثبت با صدا» در صورت پشتیبانی موتور گفتار Electron؛ ممکن است به اتصال اینترنت نیاز داشته باشد. همیشه قبل از ثبت، نام و وزن را بررسی کنید.
- بخش انتخاب و پخش دستی فایل موسیقی حذف شده است.

توجه: تشخیص گفتار فارسی در همه نسخه‌های Chromium/Electron در دسترس نیست؛ اگر میکروفون یا موتور گفتار پشتیبانی نشود، ورود دستی همچنان قابل استفاده است.
